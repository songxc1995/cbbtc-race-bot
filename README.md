A two-leg, long-only trading bot for Coinbase Wrapped BTC (cbBTC) against USDC on 1-minute on-chain bars: it buys sharp hourly capitulation drops for the bounce, and rides strong hourly momentum until it fades, each leg with its own take-profit and stop-loss.

## Run it

```sh
python3 -P -s main.py
```
